**4. Lines 64–67. The drift test still fires on sampling noise, so most rounds publish no rate.** Five reference runs and five new runs from the same distribution: the chance that all five new runs land inside the old min–max is (5/10)(4/9) ≈ 0.22 per statistic in the continuous case, so the test flags roughly 3 rounds in 4 unless the model is exactly deterministic, which no API guarantees. Counts that jitter by ±1 give the same result. Each flag retires the model and closes the pooled count, so the 20-found gate on line 61 is never reached and the rate is never printed. This is r2 item 7 narrowed, not resolved.
```
Drift: at freeze the reader runs ten times on the frozen out-of-sample set at the lowest sampling
temperature the API allows; per run, the number of set promises found and the number of
non-promises output are recorded, and the min and max of each kept. Every round starts by
re-running it five times; if three or more of the five runs fall outside either range, the round
is `reader changed`, no rate is published from it, the model id is retired and its pooled count
closes. Fewer than three outside are printed with the round and change nothing.
```
With a ten-run reference and a three-of-five rule the noise flag rate is about 4% per statistic.
