2. The dated flag is unstable, so a single read can't decide scored vs unscored. Proposed rule: 3 reads, and a
   promise is scored only if all 3 mark it dated. Disagreements go to a hand read, logged.

   changed for this agent now that it has been read with it. Any v0.4 prompt change gets a fresh test set.
